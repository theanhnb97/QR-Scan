# 00 — Product Brief

## Product statement

QR Scan is a fast native utility that understands QR/barcode content and immediately offers the action the user likely needs.

It should feel like a system utility, not a content platform.

## Product pillars

### 1. Scan
Fast camera and image decoding.

### 2. Understand
Typed parsing of scanned content instead of dumping raw text.

### 3. Act
Relevant native actions: open, copy, share, connect, call, email, add contact, navigate, authenticate.

### 4. Remember
Useful local history and authenticator metadata without leaking secrets.

### 5. Create
Generate reliable QR/barcode images from common content templates.

## Target user jobs

- “I want to know what this QR contains.”
- “I want to open this link safely.”
- “I want to scan a QR from a screenshot.”
- “I want to connect to Wi-Fi from a QR.”
- “I want to recover/reopen something I scanned earlier.”
- “I want to make a QR for a link/text/Wi-Fi/contact.”
- “I want to import a TOTP account and use its rotating code.”
- “I want a lightweight local authenticator without creating an account.”

## MVP success conditions

A user can install the app and complete the primary scanner/authenticator workflows without signing in and without a network connection, except actions that naturally require the network.
